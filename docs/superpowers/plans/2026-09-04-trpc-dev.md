> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增 `@bbplayer/trpc-dev`，用 Node HTTP + tRPC Panel 调试 `appRouter`；桌面 context 调用即抛错。

**Architecture:** 短信 HTTP 从 `phone-login.ts` 拆出，避免加载 router 时引入 electron。Node runtime 放在 `packages/main/src/trpc/node-context.ts`。新包只负责 listen 和 Panel。

**Tech Stack:** tRPC 11 standalone adapter、`@ajayche/trpc-panel`、Node `http`、Vitest、`tsx`
