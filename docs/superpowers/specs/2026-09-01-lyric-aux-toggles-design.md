# 播放页翻译 / 读音显示开关

日期：2026-09-01  
范围：`packages/renderer` 播放页；不改抓取与解析

## 目标

当前曲歌词带翻译或读音（罗马音）时，播放页可以单独开关这两条副轨。主歌词不受影响。

成功标准：

- 任意一行 `translatedLyric` 非空才出现「翻译」按钮；`romanLyric` 同理
- 歌词面板收起时这两个按钮不出现
- 默认都开；选择写入 localStorage
- 关掉后 AMLL 不再绘制对应副行（传空字符串，不改主词）
- `vp check`、`vp test`、`pnpm type-check` 通过

## 非目标

- 设置页不再做一份全局开关
- 不交换翻译与读音的上下位置
- 不做歌词编辑、偏移、手动搜索

## 交互

播放页右下角，紧挨「歌词」按钮右侧：

1. 歌词（已有）
2. 翻译（有翻译轨且歌词开着）
3. 读音（有读音轨且歌词开着）
4. 队列（已有）

按钮样式与歌词 / 队列相同：`ghost` 图标，开着 `bg-muted`，`aria-pressed`。

## 数据

AMLL 没有隐藏副轨的 props。根据开关映射一行再交给 `LyricPlayer`：

- 翻译关 → `translatedLyric: ''`
- 读音关 → `romanLyric: ''`
- 都开 → 直接用原数组，避免无谓拷贝

探测与映射做成纯函数，单测覆盖。

偏好键：

- `bbplayer.lyric-show-translation`
- `bbplayer.lyric-show-roman`

缺省或未知值视为开；仅 `'0'` / `'false'` 为关。

## 测试

- 有 / 无翻译、读音时的探测
- 开关组合下字段是否被清空
- 空白字符串不算「有轨」
