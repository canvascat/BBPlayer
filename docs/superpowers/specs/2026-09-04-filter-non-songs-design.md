# 过滤非歌曲视频

日期：2026-09-04  
范围：`packages/core` 判定；`packages/main` 设置、列表/详情/会话 tRPC；`packages/renderer` 设置开关与空态。不改数据库 schema，不删除已保存曲目。

## 目标

设置里增加「过滤非歌曲视频」开关。打开后，按 B 站分区 + 标题关键词判断是否为歌曲，主进程在返回数据前去掉非歌曲。用户看到的列表、计数、播放队列和分 P 页都只剩歌曲。关掉开关后非歌曲重新出现，本地库与收藏夹内容不被删除。

成功标准：

- 设置页有开关，默认关闭，写入 `electron-store`，重启仍在
- `isSongVideo({ tid, title })` 为纯函数，分区命中或标题命中即为歌曲
- 开关打开时，搜索、UP 主页、收藏夹、合集、稍后再看、本地下载、本地歌单、播放队列、直接打开的 BV 分 P 都不再出现非歌曲
- 本地歌单侧栏条数为过滤后的数量；远程收藏夹 / 合集 / 稍后再看侧栏条数仍用 B 站 `media_count`（不为此预拉全量稿件）
- 播放全部 / 切歌只在过滤后的列表上走；当前正在播非歌曲时，切到下一首歌曲，没有则停
- `vp check`、`vp test`、`pnpm type-check` 通过

## 非目标

- 不改 SQLite schema，不把 `tid` 写入 `bilibili_metadata`
- 不为收藏夹 / 合集侧栏数字去请求每一份稿件
- 不调用播放器 `bgm_info`、不按时长判断
- 不在搜索 API 上加 `tids=`（避免漏掉发在非音乐区、靠标题才能认出的歌）
- 不从本地歌单、收藏夹或备份里物理删除非歌曲

## 判定

放在 `packages/core`，供主进程过滤与单测使用。渲染进程不重复实现。

```ts
isSongVideo({ tid?: number | null; title: string }): boolean
```

规则（或）：

1. `tid` 落在音乐分区白名单
2. 去掉 HTML 后的标题匹配歌曲关键词

有 `tid` 且不在白名单时，仍走标题兜底。没有 `tid` 时只靠标题。

音乐分区 `tid`：

| tid | 名称           |
| --- | -------------- |
| 3   | 音乐（父分区） |
| 28  | 原创音乐       |
| 31  | 翻唱           |
| 30  | VOCALOID·UTAU  |
| 59  | 演奏           |
| 193 | MV             |
| 29  | 音乐现场       |
| 130 | 音乐综合       |
| 243 | 乐评盘点       |
| 244 | 音乐教学       |

标题关键词（去 HTML、不区分大小写，任一命中）：

- `翻唱`
- `cover`
- `原创曲`
- `official audio`
- `MV`（单词边界或 `【MV】` / `[MV]`，避免误伤 `mv` 作其它缩写的子串以外的常见写法；实现用 `\bMV\b` 与 `【MV】`、`[MV]`）
- `歌ってみた`
- `vocaloid` / `ボカロ`
- `歌切`
- `纯享`
- `官方音频`

不使用过于宽泛的 `原创`、`音乐`、`歌曲`。

## 数据

设置：

- 键：`filterNonSongs: boolean`
- 默认：`false`
- `settings.get` / `settings.set` 与现有开关相同

列表项补 `tid`（可选）：

- 搜索：`typeid`
- UP 主投稿：`typeid`
- 稍后再看：`tid`
- 收藏夹 / 合集：接口有 `tid` 就透传，没有则 `undefined`（只靠标题）
- `getVideoDetails`：view 接口的 `tid`，分 P 列表每条带上同一 `tid`
- `LibraryTrack` / 会话队列：`tid` 为可选字段；zod 与 session schema 放宽为可选。库表不存，从 DB 读出的本地曲目没有 `tid`，只靠标题

过滤发生在主进程、返回给渲染进程之前。开关变化后渲染进程重新拉设置、重新查询当前页列表，并再读一次 `session.get` 以同步播放队列。

## 主进程过滤面

当 `filterNonSongs === true` 时：

| 接口                                                                                      | 行为                                                                                                                         |
| ----------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `bili.search` / `bili.uploader` / `bili.favorite` / `bili.collection` / `bili.watchLater` | 丢掉 `!isSongVideo` 的视频                                                                                                   |
| `bili.video`                                                                              | 稿件不是歌曲则 `pages` 为空，并带 `filtered: true`（不抛错，方便分 P 页空态）                                                |
| `downloads.list`                                                                          | 过滤记录                                                                                                                     |
| `library.get`                                                                             | `tracks` 只留歌曲                                                                                                            |
| `library.list`                                                                            | `itemCount` 按该歌单曲目标题用 `isSongVideo` 重新计数（库中无 `tid`）；封面仍用库里的封面                                    |
| `session.get`                                                                             | 返回过滤后的 `queue`，`index` 映射到过滤后列表里当前曲的位置；当前曲被滤掉则落到下一首歌曲，没有则 `index` 为 0 且队列可为空 |

`library.create` / `addTracks` / 备份导入仍写入全量曲目，不过滤。

## 播放队列持久化

完整队列只存在 `electron-store` 的 `session.queue`。

`session.set` 在过滤开启时：

- 若上报队列的 id 集合是已存队列的子集（同一轮播放，只是渲染进程拿不到非歌曲）：把进度、`index`（映射回完整队列）、循环与倍速写回，**不得用过滤列表覆盖完整队列**
- 若上报队列不是子集（用户从某个已过滤列表点了播放全部，换了一轮队列）：以新队列为准写入（这一轮本来就只有歌曲）

过滤关闭时 `session.set` 保持现在的整份覆盖。

## 交互

设置页在「播放时自动缓存音频」下方增加开关：

- 标题：过滤非歌曲视频
- 说明：按分区和标题隐藏非歌曲，不删除已保存内容

打开后列表变空：沿用现有 Empty，文案说明是过滤导致，不是加载失败。

直接粘贴非歌曲 BV：进入分 P 页，看到空态「已按设置隐藏非歌曲视频」，不自动开播。

开关从关到开、且当前曲被判定为非歌曲：按 `session.get` 映射后的下一首歌曲继续；没有则停止并清空当前播放展示。

## 测试

- `isSongVideo`：音乐分区、非音乐分区但标题含翻唱 / Cover / MV、两边都不中、HTML 标题、无 tid
- `settings.get` 默认 `false`；`set` 可读写
- 列表路由在开关打开时丢掉非歌曲；关闭时原样返回
- `bili.video` 对非歌曲返回空 `pages` + `filtered: true`
- `session.get` 映射 index；`session.set` 在过滤开启且上报为子集时保留隐藏曲

## 风险

收藏夹 / 合集若没有 `tid`，只能靠标题，可能漏过滤或误杀。接受为 v1 代价，不为每条补 view 请求。
