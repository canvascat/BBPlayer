# 歌词时间轴偏移

日期：2026-09-03  
范围：`packages/main` 持久化与 tRPC；`packages/renderer` 播放页时钟与调节条。不改歌词抓取、解析、导出。

Figma：当前连接文件的 **BBPlayer** 页，`Now Playing / More Menu`、`Now Playing / Lyric Offset`。

## 目标

匹配到的歌词和 B 站音源对不齐时，用户可以按曲微调时间轴，边看词边对。偏移下次再播同一首仍生效，换歌词源也不丢。

成功标准：

- 播放页「更多 → 时间轴偏移」打开歌词右侧竖条
- 上 / 下箭头各步进 0.5 秒，滚动歌词和菜单栏当前句立刻跟着变
- 勾只收起竖条；每按一次箭头已经按曲写下
- 正数 = 歌词延后；夹在 ±10 秒
- 换歌词源、重新匹配后同一 `track.id` 仍用这份偏移
- `vp check`、`vp test`、`pnpm type-check` 通过

## 非目标

- 不改 LRC / SPL 正文，不把偏移写进导出音频的歌词文件
- 不做歌词编辑、手动搜索、全局默认偏移
- 竖条上不放「重置」（对到 0 用反方向箭头）
- 不做独立歌词窗口里的第二套调节 UI

## 数据

偏移跟曲走，和歌词缓存分开，避免换词冲掉。

- 键：与 `resolvePlay` 相同的曲目 id（已有 `track.id` 就用；否则 `generateUniqueTrackKey({ bvid, cid, isMultiPage: true })`）
- 值：秒，步长 0.5
- 存：主进程 `electron-store` 的 `lyricOffsets: Record<string, number>`
- 调回 0：删掉该键

`player.resolve` 顺带返回这首歌的偏移（没有则 0）。播放页本地改完立刻跟唱，再 `player.setLyricOffset({ trackId, offsetSec })` 写回。写盘失败不打断播放，下次再按再写。

## 时钟

正数 = 歌词延后（高亮比音频晚出现）。不改行时间戳。

- 滚动 / 菜单栏：`歌词时钟 = 播放进度 − 偏移毫秒`
- 点某一行跳转：`seek = 行时间 + 偏移毫秒`

例：歌词整体快了 1 秒，调到 `+1.0` 秒后，时间戳 10 秒那句在音频 11 秒才高亮；点那一行跳到 11 秒。

纯函数放在 renderer（与 `lyric-text` / `lyric-overlay` 同层），单测覆盖步进、夹紧、时钟、seek。

## 交互

播放页曲名旁「更多」，「时间轴偏移」放在「倍速」下面。没有歌词或歌词面板关着时该项禁用。

点开后歌词右侧出现竖向浮动条（对照移动端，不挡主词）：

1. 上箭头：偏移 −0.5 秒（歌词提前）
2. 当前值，如 `-0.5s` / `+1.0s` / `0.0s`
3. 下箭头：偏移 +0.5 秒（歌词延后）
4. 分隔线
5. 勾：收起竖条

到 ±10 秒时对应方向箭头禁用。切歌、关掉歌词面板、或勾一下，都收起竖条。新曲要再从菜单打开。

## 测试

- `歌词时钟` / `seek` 与正负偏移
- 步进 0.5、夹在 ±10、写 0 时删除 store 键
- 换歌词源后同一 `track.id` 仍读到旧偏移
- 菜单栏当前句与播放页用同一套时钟
