# BBPlayer 业务域划分说明

BBPlayer 是同一套听歌产品的多端形态：内容仍来自 B 站，歌单以本机为先，共享走独立的 BBPlayer 账号。当前按**客户端形态**拆成两份 PRD，互不替代，各自自包含。

| 文档                                                           | 覆盖范围                                                       | 交付优先级 |
| -------------------------------------------------------------- | -------------------------------------------------------------- | ---------- |
| [01-BBPlayer移动端.md](./01-BBPlayer移动端.md)                 | 现有 Android 应用（已实现）                                    | 已上线     |
| [02-BBPlayer桌面端.md](./02-BBPlayer桌面端.md)                 | 新建 macOS 桌面客户端                                          | 本期要做   |
| [03-BBPlayer桌面端技术方案.md](./03-BBPlayer桌面端技术方案.md) | 桌面端如何在原 monorepo 落地（复用业务层、重做 UI 与播放引擎） | 与 02 配套 |

关系约定：

- **业务规则对齐**：歌单类型、两套账号、共享角色、循环/下载/歌词源、校验与失败文案，桌面端与 Android 保持一致，避免用户换端后「同一操作不同结果」。
- **交互按端重做**：桌面端不用底部三 Tab，改用侧栏主窗、底栏播放条、可分离歌词窗、菜单栏迷你控制。
- **数据衔接**：两端都是本机库；BBPlayer 账号只恢复共享歌单；可用备份包在 Android 与 Mac 之间搬家。不做整库云同步。
- **不在本期**：Windows、Linux、iOS 桌面、整库云同步、用 B 站 Cookie 登录共享服务、弹幕。
